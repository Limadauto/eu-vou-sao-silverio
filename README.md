# EU VOU! — 59ª Corrida São Silvério

Editor web para o corredor colocar sua foto, ajustar o enquadramento, informar o nome e baixar/compartilhar a arte.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha `main` e `/ (root)` e salve.
6. Use o endereço gerado pelo GitHub Pages.

## Recursos
- Celular e computador.
- iOS e Android.
- Arrastar foto com toque/mouse.
- Pinça de dois dedos para zoom.
- Zoom por controle deslizante.
- Nome opcional incorporado à arte.
- Download PNG.
- Compartilhamento nativo quando suportado.
- Formato original 1024×1536.
- Formato Stories/Reels 1080×1920.
- Processamento local: a foto não é enviada a servidor.
- PWA/Service Worker.

## Observação
Para uma experiência ainda mais premium, recomenda-se hospedar via HTTPS (GitHub Pages já fornece HTTPS).
